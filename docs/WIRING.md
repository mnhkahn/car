# 接线说明（1 个 L298N 版本）

## 材料
- ESP32-S3 开发板 × 1
- L298N 电机驱动模块 × 1
- 直流减速电机 × 4
- 7.4V / 12V 锂电池 × 1
- 杜邦线 10 根左右
- 细导线（电机并联用）

**线色建议**：
- 红色 = 正极 / 电源
- 黑色 = 负极 / GND
- 其他颜色 = 信号线

---

## 第一步：4 个电机 → 并联成 2 组 → 接 L298N

L298N 只有 **OUT1/OUT2** 和 **OUT3/OUT4** 两路输出，所以 4 个电机要分成左右两组并联。

### 左轮组并联

取 **左前轮** 和 **左后轮**：
1. 两个电机的 **红线** 拧在一起 → 接 **L298N 的 OUT1**
2. 两个电机的 **黑线** 拧在一起 → 接 **L298N 的 OUT2**

### 右轮组并联

取 **右前轮** 和 **右后轮**：
1. 两个电机的 **红线** 拧在一起 → 接 **L298N 的 OUT3**
2. 两个电机的 **黑线** 拧在一起 → 接 **L298N 的 OUT4**

> 如果后面发现方向反了（发 `F` 车后退），把这组电机的两根线对调即可。

---

## 第二步：L298N ↔ ESP32-S3 信号线（6 根杜邦线）

| 从 L298N | 到 ESP32-S3 | 找板子上的丝印 |
|---------|------------|---------------|
| **ENA** | **GPIO 5** | 标有 `5` 或 `GPIO5` |
| **IN1** | **GPIO 6** | 标有 `6` 或 `GPIO6` |
| **IN2** | **GPIO 7** | 标有 `7` 或 `GPIO7` |
| **ENB** | **GPIO 8** | 标有 `8` 或 `GPIO8` |
| **IN3** | **GPIO 9** | 标有 `9` 或 `GPIO9` |
| **IN4** | **GPIO 10** | 标有 `10` 或 `GPIO10` |

---

## 第三步：共地线（最关键！1 根黑线）

| 从 L298N | 到 ESP32-S3 |
|---------|------------|
| **GND** | **GND** |

> ⚠️ **这根必须接！** 不接的话电机不转，甚至可能烧 GPIO。

---

## 第四步：电源接线（推荐分离供电）

### 电机电源（大电池 → L298N）

```
电池红线(+) ────────→ L298N +12V
电池黑线(-) ────────→ L298N GND ──→ ESP32 GND（共地线已接）
```

### ESP32 电源（单独供电，USB 或 5V 模块）

```
USB/充电宝 红线(5V) ──→ ESP32 5V
USB/充电宝 黑线(GND) ──→ ESP32 GND（已跟 L298N 共地）
```

> 💡 **为什么要分离供电？** 电机启动瞬间电流大，会把 ESP32 电压拉低导致重启。ESP32 单独用 USB/充电宝供电最稳。

## 上电前检查清单

- [ ] 左前轮 + 左后轮 → OUT1 / OUT2
- [ ] 右前轮 + 右后轮 → OUT3 / OUT4
- [ ] ENA → GPIO 5
- [ ] IN1 → GPIO 6
- [ ] IN2 → GPIO 7
- [ ] ENB → GPIO 8
- [ ] IN3 → GPIO 9
- [ ] IN4 → GPIO 10
- [ ] **L298N GND → ESP32 GND**
- [ ] 电池红线 → L298N +12V
- [ ] 电池黑线 → L298N GND
- [ ] ESP32 单独有 USB/5V 供电

## 测试

1. **先只插 ESP32 的 USB**，打开手机 nRF Connect 扫描，确认能看到 `ESP32-S3-Car`
2. **再接通电池**给 L298N
3. 连接后发送 `F`，两个轮组应该同时正转

**方向反了？** 把该组电机的两根线对调（OUT1↔OUT2 或 OUT3↔OUT4）。
